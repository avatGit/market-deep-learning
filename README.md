# Prévision de la volatilité et détection des régimes du marché des cryptomonnaies par Deep Learning

## Description

Ce projet utilise le Deep Learning pour analyser le marché des cryptomonnaies à partir des données historiques de **BTC/USDT**.

L'objectif est de développer un modèle basé sur **LSTM** capable de :

- Prévoir la volatilité du marché à court terme.
- Identifier les régimes de volatilité : **Low, Medium et High**.

Les données sont récupérées depuis Binance et traitées avec Python. Le modèle est développé avec PyTorch.

## Technologies utilisées

- Python
- PyTorch
- Pandas & NumPy
- Scikit-learn
- CCXT
- Google Colab / Jupyter Notebook
